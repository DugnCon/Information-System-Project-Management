# Báo cáo LaTeX

Biên dịch trên Overleaf:

1. Nén cả thư mục repo thành `.zip` rồi tải lên Overleaf (New Project → Upload Project). Cần tải cả repo vì báo cáo lấy hình từ `../results/figures/`.
2. Menu → **Compiler: XeLaTeX**, **Main document: report/main.tex**.
3. Bấm Recompile. Overleaf tự chạy Biber cho phần tài liệu tham khảo.

Thông tin bìa (họ tên, MSSV, lớp, giảng viên, tên trường) sửa ở đầu `main.tex`.

| File | Nội dung |
|---|---|
| `main.tex` | Cấu hình trang, phông chữ, thứ tự các phần |
| `chuong/00-bia.tex` | Trang bìa |
| `chuong/01-tom-tat.tex` | Tóm tắt |
| `chuong/02-thuat-ngu.tex` | Danh sách thuật ngữ |
| `chuong/03-mo-dau.tex` | Mở đầu |
| `chuong/chuong1.tex` … `chuong4.tex` | 4 chương nội dung |
| `chuong/04-ket-luan.tex` | Kết luận |
| `chuong/05-phu-luc.tex` | Phụ lục |
| `refs.bib` | Tài liệu tham khảo |
| `hinh/` | Hình vẽ tay (sơ đồ tư duy, mô hình…) |
