## Chỉ số đánh giá

| Viết tắt | Tiếng Anh | Tiếng Việt | Ngưỡng hay dùng |
|---|---|---|---|
| α | Cronbach's alpha | Hệ số Cronbach's alpha | ≥ 0.7 |
| CR | Composite Reliability | Độ tin cậy tổng hợp | ≥ 0.7 |
| AVE | Average Variance Extracted | Phương sai trung bình được trích | ≥ 0.5 |
| | Convergent validity | Giá trị hội tụ | |
| | Discriminant validity | Giá trị phân biệt | |
| | Fornell–Larcker criterion | Tiêu chí Fornell–Larcker | √AVE > tương quan |
| HTMT | Heterotrait–Monotrait ratio | Tỷ số dị biệt – đơn biệt | < 0.85 (hoặc 0.90) |
| | Cross-loading | Hệ số tải chéo | |
| R² | Coefficient of determination | Hệ số xác định | 0.25 / 0.50 / 0.75 |
| f² | Effect size | Quy mô tác động | 0.02 / 0.15 / 0.35 |
| Q² | Predictive relevance | Mức độ liên quan dự báo | > 0 |
| GoF | Goodness of Fit | Độ phù hợp của mô hình | 0.1 / 0.25 / 0.36 |
| | p-value / t-statistic | Giá trị p / Thống kê t | p < 0.05, t > 1.96 |

Ngưỡng ở trên ghi tạm theo bài báo và sách của Hair và cộng sự. Khi viết Chương 2 phải dẫn nguồn cụ thể cho từng ngưỡng.
